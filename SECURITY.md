# Security policy

Report vulnerabilities through GitHub private vulnerability reporting when available. Never post credentials, private repository content, production data, regulated data, or live exploit details publicly.

In scope: repository prompt injection that alters authority, secret disclosure, path traversal, execution during audit mode, graph validation bypass, unbounded loops, run-state corruption, permission escalation, unsafe self-modification, and packages containing excluded sensitive files.

Generated graphs are policy contracts, not security sandboxes by themselves. Codex sandboxing, operating-system controls, repository permissions, credential management, and human review remain required. Until a stable release, only the latest default-branch version is supported.
